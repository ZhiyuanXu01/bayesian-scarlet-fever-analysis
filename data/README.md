# Data

Individual-level scarlet fever records are not included in this public repository.

The original study data contain sensitive health, temporal, and geographic information and are subject to access and disclosure restrictions. In particular, this repository does not distribute detailed residential addresses, individual coordinates, onset or diagnosis dates, or person-level case-control records.

Public environmental and geographic source data must be obtained from their original providers. A data dictionary and expected analytical-data schema will be provided here to document the reproducible interface without disclosing restricted records.
