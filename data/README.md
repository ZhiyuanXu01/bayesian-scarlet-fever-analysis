# Data

Individual-level scarlet fever records are not included in this public
repository.

## Analytical input

The statistical workflow starts from a restricted matched case-crossover
dataset. Environmental exposures have already been linked to each case or
referent day. The required input includes:

- case and matched-referent indicators;
- pseudonymous matched-set identifiers;
- analysis covariates;
- current-day environmental exposures;
- single-day exposure lags from lag 1 through lag 10;
- variables required for descriptive, subgroup, and spatial analyses.

The original ERA5-Land and CHAP files are upstream sources and are not required
to run the statistical-analysis modules once the linked analytical dataset has
been constructed.

## Moving-average variables

Moving-average exposures are reconstructed from the matched single-day
exposure columns:

- `mavg1` is the mean from lag 0 through lag 1;
- `mavg2` is the mean from lag 0 through lag 2;
- the same definition continues through `mavg10`.

These derived columns are generated by the analysis workflow rather than
trusted as pre-existing input fields.
