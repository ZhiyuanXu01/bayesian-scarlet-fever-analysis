# Bayesian Scarlet Fever Analysis

Code and aggregate outputs for a Bayesian case-crossover analysis of short-term environmental associations with scarlet fever in Hubei and Hunan, Central China.

This repository is being prepared as a privacy-safe and reproducible companion to an MSc Applied Statistics thesis. Individual-level health and location data are not distributed.

The pooled analysis can be run on a standard desktop. Full spatial B-DLNMs
require a high-memory environment; see [`COMPUTE_REQUIREMENTS.md`](COMPUTE_REQUIREMENTS.md).
